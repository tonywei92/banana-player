Like & Add to playlist: the web dashboard

The dashboard as it is today (its own style.css and pixel icons), with the new pieces in it. Pick a size and a scene, then click around: the heart, Add to playlist, the ⋯ menus, the Liked page.

Design notes and decisions
  1. The heart sits next to the title, as on YouTube Music. On a phone it's in the title row, beside the volume button. On a computer it's in the player bar after the title, so it's there on every page, with an Add to playlist button next to it.
  2. Add to playlist on a phone is the first item of the player's ⋯ menu (the title row has no room for a third button). It opens a sheet. On a computer it opens a popover over the bar.
  3. The picker: New playlist comes first, then the playlist you last added to, then the rest. A Find field appears once there are more than 7 playlists, and what you type can become the new playlist's name. New playlist turns into a name field right there, so there's no second dialog. Liked is never listed. A playlist that already has it reads ✓ Added, and a click there asks to add it again.
  4. Liking without playing: yes, from a file's ⋯ menu (audio and video only, not folders or photos). YouTube Music lets you like any track from its menu, and here it's how you build Liked from the card without opening each file. Multi-select keeps Add (Liked excluded) and gets no Like: Liked stays one deliberate tap per thing.
  5. Liked is pinned above your playlists. Its ⋯ has no Rename or Delete. Its page has no Add files and no drag handles, because it's newest first. Each row's heart unlikes it, with Undo.
  6. Feedback: the heart's own change is the answer, so the heart shows no toast. Menu actions (Like in a file's ⋯, Unlike in a list) show a toast with Undo. A like on the handheld updates the heart here live, with the same pop, and a new row lights up on the Liked page.
