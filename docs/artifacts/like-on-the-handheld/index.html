Like on the handheld

Like & Add to playlist: the handheld

Both panels, drawn the way ui.cpp and the top panel's overlays draw them (the palette, the pixel font, the app's own glyphs, 640×480 layout units). Use the buttons, the keyboard, or click the bottom panel as if it were the touch screen.

Design notes and decisions
  1. Where Like lives: a heart in the header, right of the title, the way YouTube Music puts it. One tap toggles it. The header has room; the ten-button grid and the bottom row don't (every grid slot already belongs to a button, and a 5th bottom button would squeeze “Screen off”). There's no X Options menu on this page: X is Loop for a song and Audio & Subtitles for a video.
  2. Add to playlist is the header's second square, left of the heart. The two sit together because both mean “keep this”. Both have fixed positions, so a thumb learns them, and they never move with the title's length.
  3. With buttons: START opens the menu on a new Playing tab (Like, Add to playlist…, Show in folder, Info), ahead of Settings · About · Quit. It's only there while a song or video plays. L3 on the RG DS Plus is a shortcut for Like.
  4. Feedback: the heart turns yellow and pops. The top panel shows a card in the volume card's place: Added to Liked / Removed from Liked, with the title under it, so a Like pressed just as the song changes still says which song it was.
  5. Add to playlist: the existing “Add to…” picker. New playlist… comes first, then the last playlist you added to, then the rest. Liked is never listed. A playlist that already has it shows ✓ Added. Choosing that one asks Add again? and a second A adds it again (playlists allow repeats; Liked doesn't).
  6. Liked is pinned first in Playlists, with a yellow heart. It can't be renamed or deleted, has no Add files…, Move or Remove duplicates, and Remove becomes Unlike. It's ordered newest first and can't be reordered, as on YouTube Music.
  7. Photos: no heart, no Add, no Playing tab. L3 still rotates. Home: Recent cards show a small heart, and a card's Y menu gains Like / Unlike. The Playlists tile reads “Liked · 3 playlists”.
