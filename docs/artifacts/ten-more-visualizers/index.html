Ten More Visualizers

Ten more styles for the top panel, designed for the player's own drawing (band levels from its FFT, shapes in OpenGL). Each uses two or three theme roles on the theme's background. The large frame is Visualizer only, with the song title over it; the small one is Art + visualizer, with the style as a 200-tall band along the foot. The signal is simulated (a kick, a hat, two moving mid peaks, noise).

Theme

Cost guesses are relative to Peaks and are estimates from vertex counts and blended area, not measurements: each style still has to be timed on the handheld. All ten read the same band levels, loudness and beat hint the worker already produces, so none adds work off the GPU beyond a few hundred numbers a frame. Needles and Starfield use loudness only, no bands. Also considered and left out: a tunnel of squares (too close to Rings) and a heatmap grid (too close to Dots).
