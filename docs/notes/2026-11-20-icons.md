# Icons match the spec (2026-11-20)

- Every dashboard globe is now `G_QR` (Settings tile and page, header badge, quick settings, menus, empty states,
  Play on, the page-plays mark). `G_WEB` stays only for the manga sources' language/browser/error marks, where a QR
  would mean nothing; the web sprite never used it, so `web/sprite.svg` is unchanged.
- `G_CLOCK` (All recent, recent searches) redrawn from the spec's `clock`: square face, one hand 12 to 3.
- New `G_WIFI` (spec `wifi`: two roofs and a dot) replaces the four signal bars in the status bar; the dot shows
  1 bar, the middle roof 2, the outer roof 3+.
- Not yet audited glyph by glyph: the other spec icons (rail, keys and meanings are the owner's and untouched).
