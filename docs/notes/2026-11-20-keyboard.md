# The on-screen keyboard on the kit (2026-11-20)

- `Ui::drawKeyboard` and its key / touch code (ui_forms.cpp) are gone, with `keyboardLayout/Move/Hit/Home`, `KeyDef`,
  `ShiftState` (keyboard.h keeps `TextEdit`). The keyboard is `src/ui_keyboard.cpp`: `lay::keyboard` for the boxes,
  `lay::keyboardHit/Move/Keys` (kitlayout, tested in `testKeyboard`) for touches and the D-pad, `Kit::keyboard` to draw.
- Four layers (abc, ABC, 123, #+=), 10/9/7 keys a row, so hosts, shares and passwords need no missing key; the old
  letters page had `.`/`-`/`_`/`@` on it, they are on 123 now. Search keeps its own two-layer wiring (same kit piece).
- Password fields (Network form, Manga server) show stars; a port takes digits only.
- Check: `--press "R2,R,Y,A,A,Right,A,Select,A,Start"` types into the Network form's Name.

# Top panel: the backdrop fades out on stop

- `Ui::stopped()` now starts the leave (`leaveBackdrop`) at the stop itself: the top panel is drawn before the next
  tick, and it dropped its pages in that gap, so there was nothing left to fade.
- `TopScreen::bgLeaving` (leaving, answered, pages up) keeps page 1 and sets `bgFadeStep` from 1 to 0 off
  `Ui::backdropLeaveAt()`; the idle branch draws mpv's picture, then the page blended at that alpha
  (`drawBackdropPages(w, h, over)` with `PageRenderer::setKeepScreen`, which skips the clear). One textured quad a frame.
  `capture()` (shots) does the same. After 0.5 s the pages drop and the plain idle picture is drawn.
- Checked with a 6 s fade (temporary) and a shot at 0.36 alpha: the idle icon shows through the page; back to 500 ms.
