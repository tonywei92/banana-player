# Web dashboard: New PIN did nothing by touch (2026-11-20)

**Symptom:** the PIN could not be changed. The Y key worked; tapping **New PIN** (and **Turn off**, the switch, the
incognito button) on the Web dashboard page did nothing.

**Cause:** `Ui::Web::pointer` copied the pressed button into `id`, cleared `ui.pressedBtn`, then tested
`on(id, rect)`, whose lambda compared `id == ui.pressedBtn` (now -1): always false. Only the back arrow worked (it
tests its own rect).

**Fix:** `on()` is just the lift's hit test (the down already chose `id`). A log line now says when the handheld makes a
new PIN (`web: a new PIN from the handheld`).

**Check:** `--press "...,tap:100:410,tap:100:410"` on the page (two taps within 2 s: arm, confirm); with a signed-in
cookie: the cookie gets 401, the old PIN 401, the new one (from `web.conf`) 200. Two taps further than 2 s apart only
arm, by design.
